# 清理重复数据功能说明

## 问题描述

在开发过程中，由于使用了两个不同的函数创建示例数据：
- `initSeed` - 创建了3个来源
- `createSampleData` - 创建了6个来源

导致数据库中出现了重复的来源信息。

## 解决方案

### 1. 已优化的功能

#### 废弃 initSeed
- `initSeed` 函数已被标记为废弃
- 调用时会返回错误提示，引导使用 `createSampleData`

#### 优化 createSampleData
- 添加了去重逻辑
- 创建数据前先检查是否已存在同名记录
- 如果存在则跳过创建
- 为每个来源添加了图标和描述

#### 新增来源数据
现在创建的来源数据包含：
- **名称**: 来源的名称
- **图标**: 表情符号图标（如 💻、💼 等）
- **描述**: 来源的简短说明

示例：
```javascript
{ 
  name: '信息工程学院', 
  icon: '💻', 
  description: '计算机与信息技术相关通知' 
}
```

### 2. 清理重复数据

#### 新增云函数路由
- 路由: `dev/cleanDuplicates`
- 功能: 自动检测并删除标签和来源中的重复数据

#### 清理逻辑
1. 获取所有标签和来源数据
2. 按名称分组，保留第一条记录
3. 删除其他重复记录
4. 返回清理统计信息

#### 使用方法

**方法1：通过首页按钮**
1. 进入首页
2. 如果显示"创建数据"区域，点击 "6. 清理重复数据" 按钮
3. 查看清理结果

**方法2：通过代码调用**
```javascript
const result = await callApi('dev/cleanDuplicates', {})
console.log(result)
```

#### 返回结果示例
```json
{
  "ok": true,
  "message": "清理完成",
  "results": {
    "tags": {
      "total": 12,
      "unique": 6,
      "deleted": 6
    },
    "sources": {
      "total": 9,
      "unique": 6,
      "deleted": 3
    }
  }
}
```

### 3. 订阅页面优化

订阅页面现在会显示：
- 来源的图标（如 💻、💼 等）
- 来源的描述信息
- 更美观的列表布局

## 操作步骤

### 如果已有重复数据
1. 在首页点击 "6. 清理重复数据"
2. 等待清理完成
3. 查看清理报告
4. 刷新订阅页面查看结果

### 如果要重新创建数据
1. 先执行 "1. 初始化集合"
2. 执行 "4. 创建示例数据"（会自动去重）
3. 如有需要，执行 "6. 清理重复数据"

## 注意事项

1. 清理功能会删除重复记录，操作不可逆
2. 保留的是第一条创建的记录
3. 建议在清理前先检查数据库（使用 "5. 检查数据库"）
4. 清理完成后会自动刷新首页数据
