# 🔧 浏览历史调试指南

## 🎯 问题症状
- 浏览内容后，历史页仍然显示为空
- 历史计数显示 0

2. 右键 → 检查 / 审查元素
3. 打开控制台 (Console) 标签
4. 打开云函数日志

## ❌ 如果不工作，检查什么

### 情景 1：进入详情页时没有日志
**可能原因**：
- 没有成功进入详情页
- url 参数没有传递 `id`

**解决方案**：
```
检查 URL 是否包含 ?id=xxx
例如：/pages/detail/index?id=12345
```

### 情景 2：看到 `❌ 不记录：未登录或无内容ID`
**可能原因**：
- 用户未登录，或
- contentId 为空

**解决方案**：
```javascript
// 检查登录状态
1. 进入"我的"页面
2. 确认已登录
3. 检查用户ID是否存在

// 检查 contentId
console.log('contentId:', this.data.id)
```

### 情景 3：recordHistory 没有被调用
**可能原因**：
- `onHide()` 或 `onUnload()` 没有被触发
- 页面返回方式不对

**解决方案**：
```javascript
// 确保使用正确的返回方式
✅ 正确：点击返回按钮返回
✅ 正确：调用 wx.navigateBack()
❌ 错误：直接刷新页面
❌ 错误：用 Alt+Backspace 返回
```

### 情景 4：写入云函数时错误
**可能原因**：
- 数据库连接错误
- 权限问题
- userId 或 contentId 类型错误

**检查方式**：
```
查看云函数日志中的具体错误信息
```

### 情景 5：history/list 返回空列表
**可能原因**：
- 数据写入失败
- userId 不匹配
- 查询条件错误

**检查方式**：
```
1. 检查云函数日志中 totalCount 是否大于 0
2. 检查 userId 是否一致
3. 检查是否确实有数据被写入
```

## 📊 数据库直接查询

如果要直接检查数据库，可以在云函数中添加：

```javascript
// 添加到任何 API 路由中
case 'dev/debugHistory':
  return await debugHistory()

async function debugHistory() {
  try {
    const all = await db.collection('history').get()
    const count = await db.collection('history').count()
    return {
      total: count.total,
      data: all.data || []
    }
  } catch (e) {
    return { error: e.message }
  }
}
```

然后在小程序中调用：
```javascript
const res = await callApi('dev/debugHistory', {})
console.log('数据库中的历史记录:', res)
```
