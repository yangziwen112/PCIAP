# 雲函數部署指南

## 問題診斷

根據您的錯誤信息，主要問題是：

1. **AppID 未配置** - 已修復
2. **雲函數路徑配置錯誤** - 已修復  
3. **環境ID未設置** - 已修復
4. **雲函數未部署** - 需要手動部署

## 解決步驟

### 1. 檢查微信開發者工具設置

1. 打開微信開發者工具
2. 確保已登錄微信開發者賬號
3. 確保項目已關聯到正確的 AppID: `wx3e0ab3ad750ab3f2`

### 2. 部署雲函數

1. 在微信開發者工具中，右鍵點擊 `cloudfunctions/api` 文件夾
2. 選擇 "上傳並部署：雲函數"
3. 等待部署完成

### 3. 檢查雲開發環境

1. 在微信開發者工具中，點擊 "雲開發" 按鈕
2. 確保已開通雲開發服務
3. 記錄環境ID（格式類似：cloud1-xxxxxxxx）

### 4. 更新環境ID

如果環境ID與我設置的不同，請更新 `app.js` 中的 `envId`：

```javascript
globalData: {
  envId: '您的實際環境ID',
  // ...
}
```

### 5. 測試連接

1. 編譯並預覽小程序
2. 導航到調試頁面：`pages/debug/index`
3. 點擊 "測試雲函數" 按鈕
4. 查看調試日誌

## 常見問題

### 問題1：雲函數調用失敗
- 檢查 AppID 是否正確
- 檢查雲函數是否已部署
- 檢查環境ID是否正確

### 問題2：數據庫連接失敗
- 確保已開通雲開發服務
- 檢查數據庫權限設置
- 使用調試頁面初始化數據庫

### 問題3：權限問題
- 檢查雲函數權限設置
- 確保數據庫集合權限正確

## 調試工具

- 路徑：`pages/debug/index`
- 功能：測試雲函數、數據庫連接、查看日誌
