# 🎓 校园活动聚合平台 (PCIAP)

## 📌 项目简介

一个集成了用户登录、活动浏览、标签订阅、内容收藏等功能的校园活动信息聚合小程序。

## ✨ 核心功能

### 🔐 用户系统
- **账号密码登录**（学生/管理员身份）
- **忘记密码**（身份证验证）
- **用户信息管理**
- **退出登录**

### 🏠 首页
- **标签过滤**：5个标签快速过滤（全部、竞赛、讲座、招聘、文体）
- **活动浏览**：卡片式展示活动信息
- **收藏功能**：一键收藏感兴趣的活动
- **下拉刷新**：获取最新内容

### 📋 订阅管理
- **关注标签**：点击标签即可关注，高亮显示
- **标签详情**：查看已关注标签的详细说明
- **相关内容**：自动展示关注标签的相关活动
- **数据绑定**：订阅数据与用户账号绑定，永久保存

### 👤 个人中心
- **个人信息**：显示账号、昵称、身份
- **我的收藏**：查看收藏的活动
- **浏览历史**：查看浏览记录
- **退出登录**：安全退出

## 🎨 UI 设计

### 统一主题
- **渐变背景**：紫色渐变（#667eea → #764ba2）
- **卡片设计**：白色半透明卡片，圆角，阴影
- **交互动画**：点击缩放，平滑过渡
- **图标风格**：Emoji 表情符号

### 页面风格
1. **首页**：渐变背景 + 标签过滤 + 内容卡片
2. **订阅**：渐变背景 + 标签选择 + 相关内容
3. **个人中心**：渐变背景 + 用户信息 + 功能菜单
4. **登录**：渐变背景 + 登录表单 + 装饰元素

## 🔑 核心特性

### 1. 用户数据绑定
- 订阅数据与用户ID绑定
- 退出登录后数据保留在数据库
- 重新登录自动恢复订阅

### 2. 智能过滤
- 首页标签过滤
- 订阅页相关内容展示
- 支持多标签组合

### 3. 一键创建
- 执行一次"创建示例数据"
- 自动创建所有必需数据（用户、标签、来源、内容）
- 自动去重，不会重复创建

## 📝 技术栈

- **小程序框架**：微信小程序原生
- **云开发**：微信云开发
- **数据库**：云数据库
- **云函数**：Node.js

## 🛠️ 云函数 API

### 认证相关
- `auth/login` - 用户登录
- `auth/resetPassword` - 重置密码

### 内容相关
- `feed/recommend` - 推荐内容
- `content/list` - 内容列表
- `content/detail` - 内容详情

### 订阅相关
- `user/subscribe/get` - 获取订阅
- `user/subscribe/set` - 保存订阅

### 元数据
- `meta/tags` - 获取标签
- `meta/sources` - 获取来源
- `meta/banners` - 获取横幅

### 开发工具
- `dev/initCollections` - 初始化集合
- `dev/createSampleData` - 创建示例数据
- `dev/cleanDuplicates` - 清理重复数据

## 🔄 数据流程

```
创建示例数据
    ↓
创建用户账号（23012774）
    ↓
用户登录
    ↓
保存到本地 + 全局状态
    ↓
订阅页面关注标签
    ↓
保存到数据库（绑定 userId）
    ↓
退出登录（清除本地）
    ↓
重新登录
    ↓
从数据库恢复订阅（根据 userId）
```
