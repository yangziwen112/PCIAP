# 贡献指南

感谢你为 PCIAP（民大通）提交改进。

## 提交前检查

- 说明问题发生的页面、用户角色和可复现步骤。
- 不提交真实用户截图、微信 openid、云环境凭证、API Key、Cookie 或本地配置。
- 涉及 AI 的改动必须说明数据来源、证据边界、失败降级和人工确认点。
- 涉及采集器的改动必须保留原文链接、发布时间和来源标识，不能用模拟数据填补采集失败。
- 涉及权限的改动必须分别验证游客、普通用户和管理员路径。

## 本地验证

在小程序开发者工具中验证页面流程；云函数改动至少运行对应目录的测试和 JavaScript 语法检查。提交说明中请记录实际运行过的命令和结果，不要填写未经运行的覆盖率或准确率。

## Pull Request

PR 描述请包含：背景、用户影响、变更范围、权限影响、数据来源、测试证据、已知限制和截图（如有）。涉及模型输出时，优先提交可复现的输入与脱敏输出，不要提交隐私数据。
