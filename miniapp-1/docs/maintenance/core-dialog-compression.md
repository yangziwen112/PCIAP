# 核心对话压缩与维护协议

## 目的

本文件是本项目核心对话的短状态快照，避免长期维护时重复读取全部历史内容。它不替代聊天原文，也不保存密码、令牌或个人敏感数据。

## 每次维护前保留

- 当前目标和未完成阻塞项；
- 最近一次验证结果；
- 真实项目路径、D 盘镜像路径和是否已建立 Junction；
- 当前未提交改动边界；
- 下一步唯一优先动作。

## 每日压缩规则

1. 只保留最近一次结论、失败原因和待办，不复制完整日志。
2. 测试结果记录命令、通过/失败和日期；超过三次的重复成功结果合并为一条。
3. Git 状态只记录用户改动保护、当前分支和未提交范围，不把整份 diff 放进快照。
4. C/D 盘状态只记录源目录、镜像目录、链接状态、备份目录和校验结果。
5. 外部仓库只保留 URL、版本提交号、借鉴点和许可证注意事项。
6. 任何无法验证的线上状态必须标记为“未验证”，不能用本地通过代替线上成功。

## 当前快照更新方式

在每次每日维护结束时更新本文件的“当前状态”区；如果当前产品没有提供可调用的定时压缩接口，则由维护任务在下一次启动时先读取并压缩本文件。系统级对话上下文的自动摘要由 Codex 运行环境负责，本项目不能强制修改聊天服务内部上下文。
