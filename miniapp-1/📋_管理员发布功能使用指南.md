# 📋 管理员发布功能使用指南

## 🎯 功能概述

管理员可以在大厅（首页）通过一个加号（➕）入口，快速发布信息到平台。发布的内容会立即显示在大厅的内容列表中。

---

## 🚀 快速开始

### 步骤 1️⃣ 部署云函数

**重要**：发布功能需要云函数的支持，必须先部署。

在微信开发者工具中：
1. 找到左侧 **cloudfunctions → api** 
2. 右键点击 **api** 文件夹
3. 选择 **"上传并部署：云端安装依赖（上传全部文件）"**
4. 等待部署完成（30秒 - 2分钟）
5. 看到 ✅ **上传成功** 提示

### 步骤 2️⃣ 登录管理员账户

默认管理员账户：
- 账号：`admin001`
- 密码：`admin123`

**获取管理员账户**：
```
1. 进入首页
2. 长按标题（你好，欢迎来到PCIAP）激活开发模式
3. 点击"创建示例数据（含用户）"
4. 等待创建完成
5. 使用上述账户登录
```

### 步骤 3️⃣ 点击发布按钮

登录管理员后：
1. 在首页的标签过滤器右侧看到红色的 **➕ 发布** 按钮
2. 点击该按钮进入发布页面

---

## 📝 发布信息的完整流程

### 1. 填写基本信息

**信息标题**（必填）
- 最少 3 个字符，最多 100 个字符
- 示例：`"2024年全国大学生数学建模竞赛开始报名"`

**信息描述**（必填）
- 最少 10 个字符，最多 1000 个字符
- 详细描述信息内容、时间、地点等
- 示例：
  ```
  竞赛时间：2024年9月13日-16日
  报名截止：2024年8月31日
  参赛资格：全日制在校大学生
  奖项设置：一二三等奖及优胜奖
  ```

### 2. 选择标签（必选）

点击多个标签进行选择，已选择的标签会高亮显示：
- 🏆 **竞赛** - 各类竞赛比赛
- 🎓 **讲座** - 学术报告和讲座
- 💼 **招聘** - 招聘和实习机会
- ⚽ **文体** - 文艺演出和体育赛事
- 🤝 **志愿** - 志愿服务
- 🛠️ **工作坊** - 技能培训

**至少选择一个标签，可以多选**

### 3. 选择来源（必选）

从下拉菜单中选择信息的来源：
- 学校官网
- 学生会
- 团委
- 各学院
- 等等...

### 4. 上传图片（可选）

点击 **+ 上传图片** 按钮：
- 最多可上传 5 张图片
- 支持从相册或拍照
- 点击图片可预览
- 点击右上角 ✕ 可删除

### 5. 发布或保存草稿

**保存草稿**（可选）
- 保存当前填写的内容
- 下次打开发布页面可恢复
- 草稿保留 24 小时

**发布信息**
- 确认所有必填项已完成
- 点击 **发布信息** 按钮
- 等待发布完成
- 发布成功后会跳转回首页
- 新发布的内容会立即显示在大厅

## ✅ 发布成功的标志

发布成功后，您会看到：

1. ✅ **"发布成功"** 对话框
2. 信息内容 **"信息已成功发布到大厅"**
3. 页面 **自动返回首页**
4. 新发布的内容 **出现在内容列表中**

## ❌ 常见问题排查

### 问题 1：找不到发布按钮

**可能原因**：
- 未登录或未以管理员身份登录
- 云函数没有部署
- 小程序没有重新加载

**解决方案**：
```
1. 确认已登录管理员账户
2. 检查云函数是否已部署
3. 关闭小程序完全重新打开
4. 在首页长按标题确认开发模式
```

### 问题 2：发布时提示"参数不完整"

**可能原因**：
- 标题或描述为空
- 标签未选择
- 来源未选择

**解决方案**：
```
1. 确保标题至少 3 个字符
2. 确保描述至少 10 个字符
3. 至少选择一个标签
4. 在下拉菜单中选择来源
```

### 问题 3：发布时提示"unknown route"

**可能原因**：
- 云函数没有部署或部署失败

**解决方案**：
```
1. 返回步骤 1，重新部署云函数
2. 确保部署完成后再测试
3. 关闭小程序重新打开
```

### 问题 4：发布后内容没有出现

**可能原因**：
- 页面没有刷新
- 云函数数据写入失败
- 网络延迟

**解决方案**：
```
1. 在首页手动下拉刷新
2. 检查浏览器控制台是否有错误
3. 检查云函数日志
```

### 问题 5：提示"发布失败，请检查网络"

**可能原因**：
- 网络连接不稳定
- 云函数服务异常
- 参数格式错误

**解决方案**：
```
1. 检查网络连接
2. 稍后重试
3. 查看浏览器控制台的详细错误信息
4. 检查云函数日志
```

## 🔍 调试技巧

### 查看发布日志

在浏览器控制台中查看详细日志：

**前端日志**（微信开发者工具控制台）：
```javascript
// 发布页面加载日志
Console: 加载标签和来源...

// 发布时的日志
Console: 🚀 开始发布...
Console: 📤 即将发送 content/publish...
Console: ✅ 发布成功，响应: { ok: true, ... }
```

**后端日志**（云函数日志）：
```javascript
🚀 publishContent 被调用
参数: { userId: "xxx", title: "xxx", ... }
📝 准备写入内容...
📝 写入数据: { title: "xxx", tags: [...], ... }
✅ 内容发布成功: { _id: "xxx" }
```

### 使用 Chrome DevTools

1. 在微信开发者工具中按 **F12** 打开开发工具
2. 查看 **Console** 标签获取完整日志
3. 查看 **Network** 标签查看 API 请求和响应

## 📊 发布内容的字段说明

发布后，内容会包含以下字段：

| 字段 | 说明 | 例值 |
|------|------|------|
| title | 标题 | "数学建模竞赛" |
| description | 完整描述 | "竞赛时间：9月..." |
| summary | 摘要（前200字） | "竞赛时间：9月..." |
| tags | 标签数组 | ["competition"] |
| sourceId | 来源ID | "5f8d9f..." |
| status | 状态 | "published" |
| publishTime | 发布时间 | 1761234567890 |
| viewCount | 浏览次数 | 0 |
| favoriteCount | 收藏次数 | 0 |

## 💡 最佳实践

### ✅ 应该做

- 标题简洁明了，准确概括内容
- 描述详细完整，包括时间、地点、报名方式等
- 选择最相关的标签（可多选）
- 选择正确的信息来源
- 保存重要的草稿，避免丢失

### ❌ 不应该做

- 发布与平台无关的内容
- 使用虚假或误导信息
- 大量重复发布相同内容
- 使用特殊符号或格式破坏界面
- 发布包含个人隐私的内容
