# PCIAP 本地 QA 角色与真人路径

这里的角色是合成数据，只用于本地回归，不是线上账号，不包含密码、openid、Token 或真实用户信息。

## 角色

- 林知夏：学生读者，关注考试和学院通知；
- 周予安：学生发布者，关注校园互助和隐私提示；
- 顾言：内容运营管理员，关注采集状态、来源核验和内容治理。

## 执行路径

```powershell
node qa/simulate-real-users.js
```

脚本只校验角色、权限边界、操作顺序和敏感信息，不调用云数据库，不创建账号，不删除线上数据。

微信开发者工具中的人工回归顺序：

1. 游客：浏览首页 → 搜索通知 → 打开来源 → 提问无结果问题，确认显示 `暂无可靠证据`；
2. 学生：正式登录 → 收藏/订阅 → 发布校园动态 → 检查隐私和图片要求；
3. 管理员：正式管理员登录 → 查看采集状态 → 审核资讯 → 先查看清理范围再确认删除。

调试管理员自动登录已关闭。不要把 QA 角色导入 `users` 集合，也不要把合成数据当作真实上线数据。
