## 🚀 使用流程

### 第一次使用

1. **初始化数据库**
   - 打开小程序
   - 按顺序点击初始化按钮
   - 点击 "4. 创建示例数据（含用户）"
   - 等待创建成功，会显示账号信息

2. **登录系统**
   - 点击个人中心的"去登录"或直接进入登录页
   - 输入账号：`23012774`
   - 输入密码：`23012774`
   - 选择身份：`学生`
   - 点击"登录"

3. **使用功能**
   - 浏览活动
   - 关注标签
   - 收藏内容

### 订阅功能（与用户绑定）

**关注标签**：
1. 登录后进入"订阅"页面
2. 点击标签即可关注（会高亮显示）
3. 再次点击可取消关注
4. 订阅数据自动保存到数据库

**数据持久化**：
- 退出登录后，订阅数据保存在数据库
- 重新登录同一账号，订阅数据自动恢复
- 不同用户有各自独立的订阅数据

### 修改密码

1. 在登录页面点击"忘记密码？"
2. 输入账号：`23012774`
3. 输入身份证后四位：`6613`
4. 输入新密码
5. 确认新密码
6. 点击"重置密码"

## 🔄 完整业务流程

### 1. 登录流程
```
输入账号密码 → 选择身份 → 点击登录
    ↓
云函数验证账号密码和身份
    ↓
返回用户信息（不含密码）
    ↓
保存到本地Storage和全局状态
    ↓
跳转到首页
```

### 2. 订阅流程
```
进入订阅页面
    ↓
加载所有标签 + 用户订阅数据（根据userId）
    ↓
标记已关注的标签
    ↓
点击标签切换关注状态
    ↓
保存到数据库（绑定到userId）
    ↓
加载相关内容展示
```

### 3. 退出登录流程
```
个人中心点击退出
    ↓
确认退出
    ↓
清除本地Storage
    ↓
清除全局状态
    ↓
跳转到登录页
```

## 🎯 关键实现点

### 1. 用户身份验证
- 前端验证：账号、密码、身份三项匹配
- 后端验证：云函数双重验证
- 安全性：密码不返回前端

### 2. 订阅数据绑定
```javascript
// 云函数中使用 userId 作为关键字段
const userId = ctx.OPENID || event.userId

// 订阅保存时绑定用户
await db.collection('subscriptions').where({ userId }).update({
  data: { tagIds: [...] }
})

// 订阅获取时按用户查询
await db.collection('subscriptions').where({ userId }).get()
```

### 3. 登录状态管理
- 本地存储：`wx.storage`
- 全局状态：`app.globalData.user`
- 页面级：各页面从 auth.js 获取

## 🛠️ 云函数API

### 登录
```javascript
callApi('auth/login', {
  username: '23012774',
  password: '23012774',
  role: 'student'
})
// 返回：{ ok: true, user: {...} }
```

### 重置密码
```javascript
callApi('auth/resetPassword', {
  username: '23012774',
  idCardLast4: '6613',
  newPassword: 'new123456'
})
// 返回：{ ok: true, message: '密码重置成功' }
```

### 获取/保存订阅
```javascript
// 获取订阅（自动根据userId）
callApi('user/subscribe/get', {})

// 保存订阅（自动绑定userId）
callApi('user/subscribe/set', {
  tagIds: ['tag_1', 'tag_2']
})
```

## ⚠️ 注意事项

1. **首次使用**必须先创建默认用户
2. 每个用户的订阅数据是**独立**的
3. 退出登录会清除本地缓存，但**不会删除**数据库中的订阅数据
4. 重新登录会**自动恢复**之前的订阅数据
5. 修改密码需要正确的身份证后四位
