# 云开发配置步骤

## 1. 开通云开发

1. 打开微信开发者工具
2. 点击顶部菜单栏的【云开发】
3. 点击【开通】按钮
4. 创建新的云开发环境：
   - 环境名称：填写任意名称，如 `development`
   - 环境 ID：会自动生成，记住这个 ID
   - 付费方式：选择【按量付费】（有免费额度）

## 2. 配置云环境 ID

1. 复制新创建的云环境 ID
2. 打开 `miniapp-1/app.js`
3. 找到 `globalData.envId`，替换为你的云环境 ID：
   ```javascript
   globalData: {
     envId: '你的云环境ID', // 例如：'cloud1-7g8abcdef'
   }
   ```

## 3. 部署云函数

1. 在微信开发者工具中，展开【云开发】目录
2. 找到 `cloudfunctions/api` 文件夹
3. 右键点击 `api` 文件夹
4. 选择【创建并部署：云端安装依赖】
5. 等待部署完成

## 4. 初始化数据库

完成以上步骤后，回到小程序首页：

1. 长按顶部标题进入开发模式
2. 按顺序点击：
   - 1. 初始化集合
   - 2. 测试连接
   - 3. 测试写入
   - 4. 创建示例数据
   - 5. 检查数据库

## 注意事项

1. 确保小程序已经授权云开发权限
2. 云环境 ID 必须正确配置
3. 云函数需要成功部署
4. 如果遇到错误，可以尝试：
   - 检查云开发是否正常开通
   - 检查环境 ID 是否正确
   - 重新部署云函数
   - 刷新开发者工具
