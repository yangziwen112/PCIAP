1. ✅ 初始化集合

4. ✅ **创建示例数据（含用户）** ← 会创建用户23012774
5. ✅ 检查数据库
6. ✅ 清理重复数据（如需要）

### 步骤3: 关闭开发模式
1. 再次长按首页标题
2. 看到"开发模式已关闭"
3. 初始化按钮隐藏

现在小程序可以正常使用了！

## 👥 普通用户使用流程

### 方式一：使用预置账号登录

打开小程序 → 登录页面：
```
账号：23012774

```
点击"登录" → 完成！

### 方式二：注册新账号

1. 打开小程序 → 登录页面
2. 点击"注册"按钮
3. 填写注册信息：
   - 账号（学号）
   - 昵称
   - 密码（6-20位）
   - 确认密码
   - 身份证后四位（用于找回密码）
   - 选择身份（学生/管理员）
4. 点击"注册"
5. 注册成功后返回登录页
6. 使用新账号登录

## 🎯 关键特性

### 1. 预置用户（类似学院信息）
```javascript
// 在 createSampleData 中自动创建
{
  username: '23012774',
  password: '23012774',
  role: 'student',
  idCardLast4: '6613'
}
```

### 2. 用户注册（新用户）
- 任何人都可以注册
- 填写完整信息
- 自动保存到数据库
- 可选择身份（学生/管理员）

### 3. 订阅数据绑定
- 每个用户独立的订阅数据
- 保存在 `subscriptions` 集合
- 通过 `userId` 关联
- 退出后重新登录自动恢复

### 4. 开发模式
- 默认隐藏初始化按钮
- 长按首页标题启用
- 方便开发调试
- 不影响普通用户
