# 安全边界与漏洞报告

请不要在公开 Issue 中提交 API Key、用户身份信息、微信凭证、云数据库内容或真实持仓截图。安全问题请先通过仓库维护者的私下渠道报告，并提供复现步骤、影响范围、环境信息和最小化样例。

本项目默认遵循以下边界：

- 客户端不直接持有模型密钥、第三方接口密钥或管理员凭证。
- AI 只能使用服务端授权的公开数据和用户明确提交的数据。
- 来源不明、时间过期或证据不足时，系统应提示核验或降级，不生成确定性结论。
- 管理员接口必须经过服务端权限判断，不能仅依赖前端隐藏按钮。
- 日志不得输出 token、Cookie、完整用户标识和图片原文。

安全报告在确认前不会被包装成“已修复漏洞”；维护者会以可复现证据为准处理。
