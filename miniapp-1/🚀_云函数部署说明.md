# 🚀 云函数部署说明

## 🎯 问题

您的日志显示：
```
✅ 浏览历史已记录，响应: {error: "unknown route"}
```

**原因**：云函数中添加的新路由（`history/record` 等）还没有被部署到微信云服务器上。

---

## 🔧 解决方案：部署云函数

### 步骤 1：打开微信开发者工具

1. 打开微信开发者工具
2. 选择当前项目

### 步骤 2：找到云函数

在左侧面板找到 **云函数** 或 **Cloud Functions** 区域

应该看到：
```
cloudfunctions/
  └── api/
```

### 步骤 3：上传云函数

**方法 A：右键上传（推荐）**
```
1. 右键点击 "api" 文件夹
2. 选择 "上传并部署：云端安装依赖（上传全部文件）"
3. 等待部署完成（通常需要 30 秒 - 2 分钟）
```

**方法 B：使用菜单**
```
1. 点击顶部菜单 "工具"
2. 选择 "云函数"
3. 选择要上传的函数
4. 点击 "上传"
```

### 步骤 4：验证部署

部署完成后应该看到：
```
✅ 上传成功
✅ 已部署
```

---

## ⏱️ 等待部署完成

**重要**：请等待部署完成后再测试，不要在部署过程中关闭工具。

部署过程中可能看到：
```
📤 正在上传...
🔄 正在安装依赖...
✅ 部署成功
```

## 🧪 部署后测试

部署完成后：

1. **重新加载小程序**
   - 关闭小程序
   - 重新打开（或按 Ctrl+F5 刷新）

2. **测试浏览历史**
   ```
   1️⃣ 登录
   2️⃣ 进入详情页，浏览几秒
   3️⃣ 返回首页
   4️⃣ 进入"我的" → "浏览历史"
   5️⃣ 应该看到刚才浏览的内容
   ```

3. **查看日志**
   ```
   控制台应该不再显示 "unknown route" 错误
   而是显示 ✅ 浏览历史已记录
   ```

## ❌ 如果仍然无法工作

### 问题 1：部署失败

**症状**：
```
❌ 部署失败
错误信息：...
```

**解决方案**：
```
1. 检查网络连接
2. 确保有足够的权限
3. 尝试重新部署
4. 查看详细错误信息
```

### 问题 2：部署成功但仍然 "unknown route"

**可能原因**：
```
1. 云函数代码中的路由没有被正确添加
2. 代码中有语法错误导致 switch 语句失效
3. 小程序没有重新加载
```

**解决方案**：
```
1. 手动检查 cloudfunctions/api/index.js 中的 switch 语句
2. 确保 case 'history/record': 存在
3. 完全关闭小程序并重新打开
4. 清除微信缓存
```

### 问题 3：看到正确的日志但没有数据

**可能原因**：
```
1. 数据库集合没有创建
2. 数据库权限问题
```

**解决方案**：
```
1. 在小程序首页点击 "初始化集合"
2. 等待完成
3. 重新测试浏览历史
```
